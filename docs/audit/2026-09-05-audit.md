**P0-1 · 17 个 L2 脚本的 main 守卫在符号链接 / 含空格路径下静默失效，`install.js` exit 0 且不写任何文件**

- 证据：
  - 裸 href 比较 `if (import.meta.url === \`file://${process.argv[1]}\`)` 出现在 `scripts/install.js:458`、`update.js:94`、`uninstall.js:237`、`status.js:344`、`doctor.js:1190`、`audit.js:156`、`clean-residue.js:473`、`toggle.js:44`、`sampling-audit.js:1015`、`hard-rules-audit.js:214`、`lesson-bypass-audit.js:318`、`sparkline.js:195`、`safety-coverage-audit.js:431`、`spec-coherence-audit.js:620`、`version-cascade-check.js:305`、`baseline-metrics.js:862`、`lint-argv.js:254`（17 处）。
  - 正确实现（realpath 双侧）只有 `scripts/design-detect.js:386-392` 与 `scripts/statusline-adopt.js:30-36`；`design-detect.js:381-385` 的注释已写明"a bare href compare ... the CLI block never runs and stdout is silently empty"；`scripts/lint-argv.js:85-88` 注释亦承认"the shape that survives a symlinked invocation"。知道、修了两个、其余没跟。
  - 沙箱复现（`HOME` 指向空目录，仓库通过软链目录调用）：`node <symlink>/scripts/status.js` 输出 **0 字节** exit 0；同一命令走真实路径输出完整 JSON。`node <symlink>/scripts/install.js` exit 0，`$HOME/.claude/.claudemd-manifest.json` **不存在**。复制到含空格的目录 `sp ace/scripts/status.js` 同样 0 字节（`file://` 拼接不做百分号编码，`import.meta.url` 是编码后的）。

- 影响：用户把 `~/.claude` 做成 dotfiles 软链（ARCHITECTURE:176 已把 `settings.json -> dotfiles/…` 列为支持场景）时：每次 SessionStart 走 fresh-install 分支 → `install.js` 4 s 内"成功"返回却无 manifest → 下一会话再次进入同一分支，spec 永远不落盘，无任何 banner；`/claudemd-status` `/claudemd-doctor` `/claudemd-update` 等 13 个 slash command（16 个中除 design-adopt / statusline / refresh 外）输出为空。失败方向是静默通过，与 R11 记录的"gates that were passing"同类。

- 预估改动：helper ~15 LOC + 19 处各 1–3 行 + lint 规则 ~10 行 + 测试 ~40 行 ≈ 90 LOC，20 文件。
- 风险：低。行为只在"当前不工作"的路径上改变；真实路径下 `realpathSync` 与 href 比较等价。注意 `bin/claudemd-lint.js` 无守卫（bin 入口），不在范围。
