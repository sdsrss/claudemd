## v9.0.0 (major, 2026-11-25) — The core keeps only what the model does not do by default

Design record `tasks/specs/spec-v9-lean-2026-11-25.md`; analysis `docs/claudemd-value-assessment-2026-11-25.md`. Major: the core goes from 24,218 bytes (v8.6.0, the last released core; v8.6.1 below was never released) to 2,792 bytes, seven of the nine modules are deleted, and 11 HARD rules are removed.

- **Why**: the first outcome A/B of this spec (nine coding tasks judged by hidden tests, Claude Opus 5.5 at xhigh, 432 runs) found that with v8.6.0 installed the code was as correct as with no spec or less (65/72 and 60/72 against 65/72) at 1.8–2.4 times the cost, and that Opus 5.5 without any spec already kept failing assertions, reported pre-existing red tests, fixed root causes, synced docs and stayed in scope. Followed strictly, v8's "adjacent defect goes under open items, not into the diff" made the model leave a second path of the reported bug unfixed. The lean text kept correctness (66/72) at 1.2–1.3 times the cost, with a local commit and a `## 汇报` report in 41 to 72 of 72 runs, depending on how the spec was delivered (41/72 with the spec in the repo, below the ≥ 46/72 bar also set before the run). Its cost, 1.17 and 1.26 times by delivery channel, missed the ≤ 1.15 bar written down before the run; the user accepted that on 2026-11-25.
- **Core keeps**: §1 language; §5 the ask-first list and the `[AUTH REQUIRED]` line; §7 one local commit per change, push/tag/release only when asked, "done" only after a check ran this session; §8 the safety lines (`rm` on an empty-able variable, secrets, SSL, `WHERE`, unknown-origin scripts, `~/.claude/` scans, a hook's bypass token or `DISABLE_*` switch is the user's to use, temp files); §10 the three-part report, with 遗留 narrowed to what the user must decide or know; §12 read the ship module before a release.
- **Removed from the core**: L0–L3 levels, Iron Laws #1 and #3, spec files and plans, the module routing table, parallel-path completeness, the glossary, the trust order, `AUTONOMY_LEVEL`, the session rules (turn-yield, post-compaction, session exit), the banned-vocabulary list and the honesty sub-rules, and "a defect found next to the task goes under open items, not into the diff".
- **Modules**: `auth`, `debug`, `memory`, `orchestrate`, `plan`, `session` and `verify` are deleted; `ship` and `review` are rewritten. The pre-tag review now runs only when a release changes a delete or cleanup path, auth or secrets, install/update/publish/release scripts, a gate's decision, a data format or migration, or a published package's default behaviour, or when the user asks. Review findings: wording-only Lows no longer start a round; a second miss on the same item stops and asks the user.
- **HARD rules**: removed `§0-hard-auth-override`, `§7-user-global-state`, `§8-verify-before-claim`, `§10-honesty`, `§11-mid-spine-yield`, `§11-post-compaction`, `§9-parallel-path`, `§iron-law-3`, `§iron-law-1`, `§7-EXT-evidence-validity`, `§11-O-subagent-non-convergence`. The §13 META 30-day grace for HARD-rule removal was waived by the user on 2026-11-25, with the A/B above as the rationale. `§10-specificity`, `§11-memory-read` and `§11-session-exit` stay as hook-enforced rules documented in extended §13; every kept rule keeps its ID. 15 HARD rules remain: 7 hook / 6 self / 1 both / 1 external.
- **§0.1** caps: core 4,000 bytes, extended 12,000 bytes; a new or stricter rule needs an outcome run showing it changes results.
- **Not in the tested draft**: the §8 bypass line (v8's §8 Escape tokens, kept because every hook deny cites it), and the `curl` / `wget` clause of the unknown-origin line (the `§8-curl-sh` hook's anchor). Together 218 bytes over the 2,574-byte draft the A/B ran (`tasks/claudemd-value-2026-11-25/lean/CLAUDE.md`). Also untested: `ship.md` and `review.md` as rewritten here, since the A/B's lean arms loaded v8.6.0's modules unchanged.
- **Hook texts** (plugin 0.122.0, verdicts unchanged): the memory-read, banned-vocab and session-exit messages point at extended §13 "Hook-enforced rules" instead of the removed core §10 / §11; ship-baseline's deny points at `ship.md` and its heading no longer names core §7; the npx and fetch deny of pre-bash-safety quotes the v9 §8 lines, and its fix list says to ask first instead of offering a pinned version (its per-hit line still says "unpinned", and a pinned version still passes the gate: `docs/S8-RESIDUALS.md` F17); the temp-pressure note of tmp-sweep no longer points at the deleted `auth.md` and leaves what an earlier session left to the user; the rework note and the memory hint cite no section; deny texts call the bypass rule core §8 instead of v8's "§8 Escape tokens". Other hooks' messages were not reworded; `spec-module-gate`, `sandbox-disposal-check`, `residue-audit`, `mem-audit` and several opt-in hooks still name v8 sections.
